# Community Growth Plan

This checklist keeps the repository ready for first-time contributors.

## Launch Checklist

- [ ] README title, links, and contribution paths are current
- [ ] Old repository links are removed
- [ ] `good first issue` is available without an emoji prefix
- [ ] Beginner issue labels exist: `available`, `claimed`, `no-code`, `10-minute-task`, `30-minute-task`, `1-hour-task`
- [ ] Translation issues include acceptance criteria and claim instructions
- [ ] Game idea issues include a small spec and acceptance criteria
- [ ] GitHub Pages is enabled with source set to GitHub Actions
- [ ] Discussions are enabled
- [ ] A Start Here issue is pinned
- [ ] Repo topics are focused and typo-free

## Curated Starter Backlog

Use a mixed starter set like this for the main `good first issue` view:

1. `[10-minute] Fix typo in README`
2. `[10-minute] Add Turkish README translation`
3. `[10-minute] Improve README translation instructions`
4. `[30-minute] Add Hangman CLI game`
5. `[30-minute] Add Quiz CLI game`
6. `[30-minute] Improve Number Guessing README`
7. `[30-minute] Add screenshots to Beginner Guide`
8. `[1-hour] Add Memory Card web game`
9. `[1-hour] Add search filter to Games page`
10. `[1-hour] Add Typing Speed web game`
11. `[docs] Add a short FAQ for first-time contributors`
12. `[bug] Improve empty leaderboard state`

Keep the remaining translation ideas in a translation backlog issue or milestone so the issue list feels curated rather than automatically generated.
