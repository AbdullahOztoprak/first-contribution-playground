# Maintenance Policy

First Contribution Playground is maintained as a beginner-friendly open-source learning space.

## Review Promise

- Beginner PRs are reviewed with guidance.
- Questions are welcome, even when they feel small.
- Requested changes should explain what to fix and why.
- Rejected changes should be handled respectfully.

## What We Accept

- README and documentation translations
- Small CLI, web, or algorithm games
- Documentation improvements
- Beginner guide improvements
- Small website improvements
- Security and workflow fixes that make contribution safer

## Generated Files

Generated data files should not be edited manually in contributor branches:

- `data/games.json`
- `data/contributors.json`
- `data/leaderboard.json`

These files are regenerated by automation from source content.

## Claimed Issues

- Contributors should comment `I'd like to work on this` before starting an issue.
- Maintainers may mark the issue as `claimed`.
- If there is no visible activity for 7 days, the issue may be marked `available` again.

## Review Timing

Typical review time is 24-72 hours. Volunteer availability can vary, but beginner PRs should not sit without a response when maintainers are active.
